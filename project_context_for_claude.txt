== PROJECT CONTEXT: MSc Thesis by Florian Katzmann ==

GOAL
----
Classify German parliamentary speeches (Bundestag, legislative periods 13–20) into
Manifesto Project policy domains using ManifestoBERTa, then link results to IMF
conditionality data.


DATA PIPELINE OVERVIEW
----------------------
1. R script extracts speeches from the GERMAPARL2 CWB corpus using polmineR
2. R script cleans and splits speeches into sentences, saves a CSV
3. Python script loads that CSV and runs ManifestoBERTa on each sentence
4. Output CSV has the original columns plus a predicted policy label and confidence score


R SCRIPT: Script_Speechrefinement.R
------------------------------------
What it does step by step:

Step 1 — Corpus extraction
  - Uses polmineR + a local CWB corpus called GERMAPARL2
  - Filters to legislative periods 13–20, p_type = "speech",
    speaker_role in {mp, government}
  - Segments into individual speeches using as.speeches() with a 500-token gap

Step 2 — Text extraction per speech
  - Extracts: speech_id, speaker name, party, date, full text (words joined with spaces)

Step 3 — Cleaning
  - Removes parenthetical stage directions like (Beifall), (Zwischenruf) using regex
  - Drops speeches with fewer than 100 words after cleaning

Step 4 — Sentence splitting
  - Splits each speech on sentence-ending punctuation: (?<=[.!?])\s+
  - Adds context_before (previous sentence) and context_after (next sentence)
  - First sentence of each speech has NA for context_before
  - Last sentence of each speech has NA for context_after

Step 5 — Saves two files:
  - Data/sentences_for_classification.csv  (flat CSV, input for Python)
  - Data/sentences_dt.rds  (same data as an R data.table)


CSV FORMAT: Data/sentences_for_classification.csv
--------------------------------------------------
~6 million rows. Columns:

  speech_id          string   Unique ID per speech, format: "<speaker_name>__<n>"
  legislative_period integer  13 to 20
  speaker            string   Speaker's full name
  party              string   Party abbreviation (CDU, SPD, FDP, etc.)
  date               string   ISO date of the plenary session (YYYY-MM-DD)
  sentence_nr        integer  1-based position of the sentence within the speech
  sentence           string   The sentence text to classify
  context_before     string   Previous sentence; NA/empty for first sentence in speech
  context_after      string   Next sentence; NA/empty for last sentence in speech


PYTHON SCRIPT: Scripts/classify_manifestoberta.py
--------------------------------------------------
Model:
  manifesto-project/manifestoberta-xlm-roberta-56policy-topics-context-2023-1-1
  (from HuggingFace, installed locally, runs on GPU)
  56-class classifier using Manifesto Project policy domain codes.

Input format for the model:
  The three text fields are joined with " </s></s> " as separator:
    [context_before] </s></s> [sentence] </s></s> [context_after]
  If context_before or context_after is NA/empty, that field is omitted from the join.

What the script does:
  - Reads sentences_for_classification.csv in chunks of 10,000 rows
  - For each chunk, runs ManifestoBERTa in batches of 32 sentences on GPU
  - Appends results to Data/sentences_classified.csv
  - Resume-safe: if the output file already exists it counts existing rows and skips them,
    so the script can be stopped and restarted without redoing work

Output file: Data/sentences_classified.csv
  Same columns as the input CSV, plus:
    label  string   Manifesto policy code predicted by the model (e.g. "per401")
    score  float    Softmax confidence for the predicted label, rounded to 4 decimal places

To run:
  cd "S:/RProj_MSc/MScThesis"
  python Scripts/classify_manifestoberta.py
