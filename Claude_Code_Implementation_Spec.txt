3.3.2 Implementation outline
Load speech RDS once; build the master probability matrix prob_mat (n_sent × 56) exactly as today.
For each τ ∈ TEMPERATURES:
Build prob_mat_tau via temper(prob_mat, τ) (helper already exists).
Run the existing per-cell soft-aggregation loop on prob_mat_tau for both Aggregation A and Aggregation B; store results under speech_dists[[paste0('soft_tau', τ, '__A')]] and …__B.
For each threshold ∈ CONF_THRESHOLDS: run hard_aggregate on the native-τ prob_mat for both schemes; store under hard_thr0.4__A, hard_thr0.4__B, hard_thr0.5__A, hard_thr0.5__B.
For the tightened pre-filter variant: build a logical mask on the speech rows (using the columns specified in TIGHT_FILTER), subset prob_mat to the surviving rows, then re-run the native-τ soft-aggregation on that subset for both schemes; store under tightprefilter__A and tightprefilter__B. Save the per-cell sentence count n_sent so 10_robustness_prefilter.R can report drop rates.
Save the primary (native, soft) probability matrix and cells index to speech_prob_matrix.rds exactly as today. The bootstrap in H1a uses these.
Memory note: prob_mat for the full corpus may be large (a few GB if ~10M sentences). The temperature loop is O(n_sent × 56 × 3 + per-cell aggregation × 3). Doing it in one process is fine on the RTX 5070 laptop; if memory is tight, free prob_mat_tau between iterations explicitly with rm() and gc().

7. Known pitfalls Claude Code should not stumble over
7.1 The FDP LP 18 cell
Empirical findings report explicitly excludes "FDP LP 18 (n=320 sentences from non-fraction speakers)" — this is because FDP was extra-parliamentary in LP 18 and the speech sentences flagged with party=FDP in that LP come from individual non-fraction speakers, not a parliamentary fraction. The current pipeline does NOT explicitly exclude this cell — it relies on the cell having low n_sent and being filtered downstream. Behaviour to keep: the cell shows up in caches with n_sent in the low hundreds; downstream scripts can either (a) drop cells with n_sent < some threshold, or (b) keep them and accept the noise. Recommendation: leave the existing implicit handling in place (the cell has very low n_sent, statistically negligible influence) but add a stop-warn message in 03_load_and_aggregate.R if any cell in the cache has n_sent < 1000, so Flo is alerted in code review.
7.2 Manifesto-side Aggregation B Andere mass
On the speech side, Andere mass is computed as 1 − sum(BUCKETS_B) because the soft probabilities partition correctly. On the manifesto side, the same logic is used in 03_load_and_aggregate.R via aggregate_manifesto_row, but the per-category MARPOR percentages may not sum to exactly 100 (uncoded "H" share). This is handled in pull_marpor_align.R by renormalizing to unit sum before joining. Verify this is still the case after any refactoring; if it's not, the Andere mass on the manifesto side will be biased.
7.3 Linke labeling across LPs
MARPOR uses three IDs for the German left across the period (PDS, Linkspartei.PDS, Die Linke). The normalize_party() function in 02_helpers.R folds these into "Linke". Do not introduce sub-period splits; treat "Linke" as a single party across LP 13–20 for all hypotheses (this matches MIv2 §1.1 and the empirical findings report).
7.4 AfD enters in LP 19 only
AfD has only 2 speech-side cells (LP 19, LP 20). On the manifesto side, AfD has manifestos for the 2013, 2017, and 2021 elections. For H1a/H1b/H2/H3, AfD contributes only LP 19 and LP 20 cells. For H4, the Dalton-weighted polarization at LP 13–18 with AfD's seat share = 0 and vote share ≤ 5% (or 0) means AfD contributes essentially nothing. This is by design (and is why H4 reports both "all parties" and "excl. AfD" lines).
7.5 polarization_score: positive = right-coded everywhere
The sign convention used throughout the pipeline (and matched in the H4 mean-position figure caption) is: positive = market-liberal / retrenchment / restrictive / Eurosceptic. Do not invert this for any single domain. If a future hypothesis requires a left-coded sign (e.g. for a particular plot), invert in the plotting code, not in polarization_score.
7.6 Manifesto data on AfD pre-2013
AfD has no manifesto before 2013. For LPs 13–17, AfD has no manifesto and no parliamentary representation, so it is absent from H1a/H1b/H2/H3 cells. Don't try to backfill; an absent cell is the correct behaviour.
